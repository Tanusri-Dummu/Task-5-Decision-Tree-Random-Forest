# 🌳 Task 5: Decision Tree & Random Forest

## 📌 Objective
To build machine learning models using **Decision Tree** and **Random Forest** algorithms and compare their performance.

---

## 📂 Dataset
- Heart Disease Dataset (CSV)
- Features include: age, sex, chest pain type, cholesterol, etc.
- Target: presence or absence of heart disease

---

## ⚙️ Tools & Libraries Used
- Python 🐍
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Graphviz

---

## 🧠 Machine Learning Steps

### 1. Data Preprocessing
- Loaded dataset using Pandas
- Checked data structure and columns
- Separated features (X) and target (y)

### 2. Train-Test Split
- Data split into training and testing sets (80/20)

### 3. Decision Tree Model
- Trained DecisionTreeClassifier
- Controlled overfitting using max_depth
- Predicted test results

### 4. Random Forest Model
- Trained RandomForestClassifier
- Combined multiple decision trees
- Improved accuracy compared to single tree

---

## 📊 Evaluation
- Accuracy score used for comparison
- Random Forest performed better than Decision Tree

---

## 📈 Visualizations
- Accuracy comparison bar graph
- Decision Tree visualization
- Feature importance graph
- (Optional) scatter plots for data understanding

---

## 🏆 Results
- Decision Tree: Moderate accuracy
- Random Forest: Higher accuracy and better stability
- Conclusion: Random Forest is more reliable
